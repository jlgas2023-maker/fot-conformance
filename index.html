FOT Conformance Suite

Read-only, zero-backend tooling for Robinhood Chain: distinguishing declared fee-on-transfer tokens from concealed drainers, catching data providers that mishandle burn-decreasing supply, and a generic token dashboard. Nothing here launches, trades, holds funds, or requires a wallet connection. See docs/methodology.md for the full rationale.

Supply Conformance live

On-chain totalSupply vs. what each external provider reports, sampled on a schedule and committed as tamper-evident history.

FOT Taxonomy Scanner stub

Classifies any ERC20 as clean, declared-FOT, or suspect via static + eth_call-only dynamic analysis.

Token Dashboard live

Generic, config-driven price/supply/holder dashboard for any ERC20 on any EVM chain.

Chain Infrastructure QA live

RPC latency, Blockscout indexing lag, and verified-source coverage over time. Router compatibility not yet implemented.
